# EvgeshaXT - Логово EvgeshaXT

## Описание
Данный проект представляет собой мой личный сайт-родной дом, разработанный на ASP.NET Core Razor Pages. На данный момент сайт поддерживает 2 языка (русский и английский) и является удобным местом для публичного хранения различных видеофайлов.

## Переключение языков и SEO

Сайт использует кастомный Middleware в `Program.cs` для определения языка пользователя на основе URL, куки и заголовков браузера (`Accept-Language`). 

## Структура проекта

EvgeshaXT-site/

├── Pages/ - Страницы сайта
│   ├── Shared/ - Общие компоненты
│   ├── Videos/ - Страницы категорий видео (EN)
│   └── Ru/ - Локализованные страницы (RU)
├── Resources/ - Словари ресурсов для локализации
├── wwwroot/ - Статические файлы
│   └── css/ - Стили
├── Program.cs - Главный файл программы
├── VideoManager.cs - Видео-менеджер
└── README.md - Этот файл
